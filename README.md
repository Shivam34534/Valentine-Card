# Valentine's Day Card 💝

An interactive Valentine's Day web app built with HTML5 and Tailwind CSS. Click "Yes" to celebrate or watch the "No" button change with charming messages!

## Features
- Interactive button responses
- Animated celebration screen
- QR code generator for sharing
- Responsive design
- Uses Bugcat Capoo GIFs for charm

## How to Use
1. Open `Valentine.html` in your web browser
2. Click "Yes" or "No" to interact with the app
3. Use the "Share App (QR Code)" button to generate a QR code to share with your Valentine

## Technologies
- HTML5
- CSS3 with Tailwind CSS
- JavaScript (vanilla)

Enjoy! ❤️
